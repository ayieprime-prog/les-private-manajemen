# Les Private Manajemen

Aplikasi manajemen lembaga les private multi-cabang.

## Modul

**Fase 1 (MVP)**
1. Manajemen Cabang & Pengguna (Admin Pusat, Admin Cabang, Tutor, Ortu/Siswa)
2. Penjadwalan Sesi
3. Absensi
4. Pembayaran & SPP
5. Perkembangan Siswa & Laporan Ortu
6. Manajemen Tutor & Penggajian

**Fase 2**
7. Perpustakaan materi ajar internal
8. CRM pendaftaran/trial & referral
9. Notifikasi WhatsApp otomatis
10. Laporan keuangan konsolidasi per cabang
11. Rating/evaluasi tutor

## Stack

- Frontend: React + Vite + Tailwind CSS
- Backend: Express + Prisma + PostgreSQL
- Deploy: Railway
